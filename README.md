尾矿库检测数据集![在这里插入图片描述](https://i-blog.csdnimg.cn/direct/e545624f8ae8460fb02b9ba2cc25d9b6.png)


尾矿库是采矿所必需的基础设施，也是高势能人为泥石流的风险来源。存在溃坝的危险，可能造成重大的人员、经济损失和环境灾难。遥感影像中尾矿池的目标检测是在遥感影像中识别和定位尾矿池。它在找出尾矿池的分布和数量并进行动态监测方面发挥着重要作用。本数据集共1183张图像（图像尺寸为1024×1024尺寸），共标注1728个尾矿实例，数据量2GB；
数据集分别在2016年、2018年、2020年和2021年采集四年不同的样本数据，数据都基于国内光学卫星图像，空间分辨率2米；使用有向检测框标记（ID0051）

标注格式如下：
583.2 659.1 896.6 503.5 818.8 346.9 505.4 502.5 tailing_pond
121.7 510.3 216.0 362.5 111.5 295.8 17.2 443.6 tailing_pond
359.9 450.8 491.9 312.6 415.8 239.9 283.7 378.1 tailing_pond

仅1类：tailing_pond 尾矿池，采用旋转框标注，适配遥感影像里不规则尾矿池轮廓，应对倾斜、大面积水域场景。

大范围卫星遥感尾矿库自动普查，统计尾矿库数量与空间分布
多年时序遥感影像，尾矿库面积动态变化监测
